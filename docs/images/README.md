## 更新截图

1. 在 LibreOffice 或相应 Office 应用中打开原始示例并导出 PDF。Excel 导出时每张工作表应缩放到单页，避免横向截断。
2. 检查中文字体是否完整显示。当前截图使用了本机的楷体、宋体与中文无衬线字体替代；不同渲染器的字体及分页可能略有差异。
3. 将所需页面或图表区域导出为约 1800 像素宽的 PNG，保留上述文件名。
4. 检查截图中的中文、表头、图例和边缘，再核对 README 中的说明和源文件链接。

注意：示例中的图表与表格可能采用不同细项假设。截图保留原始内容，README 不将它们作为已核验的真实投资结论。
